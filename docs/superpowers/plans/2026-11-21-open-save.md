# Open, Edit and Save Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Open one UTF-8 Markdown file from the command line in a plain CodeMirror 6 editor and save it with `Mod-s`, byte-exact for untouched content.

**Architecture:** Rust only moves bytes and hands over the startup path. The frontend decodes bytes (BOM, UTF-8), keeps the original text as a base, tracks CodeMirror change sets since the base, and on save rebuilds bytes by copying unchanged stretches from the base.

**Tech Stack:** Tauri 2, TypeScript, CodeMirror 6 (`@codemirror/state`, `@codemirror/view`, `@codemirror/commands`), Vitest, Rust.

**Spec:** `docs/superpowers/specs/2026-11-21-open-save-design.md`

## Global Constraints

- Never re-serialize; untouched bytes identical after save.
- UTF-8 only; UTF-16 BOM or invalid UTF-8 → error text `lookdown only opens UTF-8 files`.
- Dominant line ending: most frequent of `\n`, `\r\n`, `\r`; ties and no line breaks → `\n`.
- Title `<name> — lookdown`, dirty prefix `• `.
- `withGlobalTauri: false`; CSP set (see spec); `core:window:allow-set-title` granted.
- Fixtures under `tests/fixtures/` are byte-exact; never let an editor or git rewrite them.
- Frontend tests: `pnpm test`. Rust tests: `cargo test --manifest-path src-tauri/Cargo.toml`.

## Review Focus

1. Edits touching a line ending (delete a CRLF, join lines, type at end of a CRLF line): untouched endings on both sides must survive. Covered in Task 2.
2. Undo back to the saved text then `Mod-s`: must write nothing (no endings rewritten by re-insertion). Covered in Task 3.
3. Save after save: the base resets; a second edit must map against the new text, not the original. Covered in Task 3.
4. A file whose first bytes are a UTF-8 BOM followed by nothing (BOM-only file): must round-trip. Covered in Task 1.
5. Save failure (read-only file, path gone): document stays dirty, error shown, base unchanged. Covered in Task 3.

### Task 2: Line map and exact serialization

**Files:**
- Create: `src/file/lines.ts`, `src/file/lines.test.ts`

**Interfaces:**
- Consumes: `decode`, `encode`, `fixture`, `FIXTURES` (Task 1).
- Produces: `type Eol = "\n" | "\r\n" | "\r"`; `interface Base { raw: string; eol: Eol; lineStarts: number[] }`; `makeBase(raw: string): Base`; `normalized(base: Base): string` (all endings → `\n`); `rebuild(base: Base, changes: ChangeSet): string` (raw text with endings).

- [ ] Step 1: tests (using `EditorState.create({ doc: normalized(base) })` and `state.update({ changes })`):
  - `rebuild(base, ChangeSet.empty(len))` equals `base.raw` for every fixture.
  - `normalized(base)` equals CodeMirror's `state.doc.toString()` for every fixture (same line split).
  - mixed: replace a word on the CRLF line → only that word differs in `rebuild` output vs raw.
  - crlf: insert `"\n"` mid-line → output gains exactly one `\r\n`.
  - mixed: delete the line break between the LF line and the CRLF line (join) → the other endings unchanged.
  - crlf: type at end of a line (before `\r\n`) → ending kept after the typed text.
  - `makeBase("a\r\nb\r\nc\n").eol === "\r\n"`; `makeBase("x").eol === "\n"`; tie `"a\nb\r\nc"` → `"\n"`.
- [ ] Step 2: `pnpm test` → FAIL.
- [ ] Step 3: implement. `lineStarts[i]` = raw offset of line i; normalized offset `p` on line i (via a normalized line-start array or `Text.lineAt`) maps to `lineStarts[i] + (p - normLineStart[i])`. `rebuild` walks `changes.iterChanges`, copying `raw.slice(map(prevA), map(fromA))` for gaps and `inserted.toString().replaceAll("\n", eol)` for inserts, then the tail.
- [ ] Step 4: `pnpm test` → PASS. Commit `feat: rebuild raw text from CodeMirror changes`.

- [ ] Step 1: tests:
