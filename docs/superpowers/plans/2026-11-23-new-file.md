# New File Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `Mod-n` (and "New…" in the macOS File menu) asks for a location in the native save dialog, creates an empty Markdown file there, and opens it as a normal tab.

**Architecture:** Rust gets one command, `create_file`, which never overwrites (`create_new`). The frontend picks a path, appends `.md` when there's no extension, creates the file, then reuses the existing `openPaths` route. That route already handles the duplicate-tab check, file watching and the rest. There are no pathless tabs.

**Tech Stack:** Tauri 2 (`tauri-plugin-dialog` `save`), TypeScript, Vitest, Rust with `tempfile` in tests.

**Spec:** `docs/superpowers/specs/2026-11-23-new-file-design.md`

## Global Constraints

- Never empty or change an existing file: creating uses `create_new`, and an existing path is opened unchanged.
- The new file is 0 bytes. The first save writes LF and no BOM (current `makeBase` default; no code change).
- Default name `untitled.md`. Dialog filters: `OPEN_FILTERS` (Markdown `md`/`markdown`, then All files).
- No extension → append `.md`. "No extension" means the file name has no `.` after its first character.
- Status copy, exactly: `<name> already exists; opened it.` and `Could not create <path>: <error>` and `Could not show the save dialog: <error>`.
- Empty page copy, exactly: `Create a file with Ctrl+N, open one with Ctrl+O, or drop one here.` / `Create a file with ⌘N, open one with ⌘O, or drop one here.`
- No new dependencies. The code is cross-platform, and paths keep their native separators when passed to the dialog.

## Review Focus

1. **The user confirms "Replace" on an existing non-empty file** → its bytes stay identical and it opens as a clean tab with the "already exists" status (Task 3 test `existing file opens unchanged`).
2. **The name has no extension and `name.md` is already open in a tab** → that tab is focused, with no duplicate tab and no write (Task 3 test `appended name that is already open focuses its tab`).
3. **The save dialog itself fails** (plugin error, missing permission) → status `Could not show the save dialog: …`, and nothing is created (Task 3 test `dialog error shows a status`).
4. **Windows active-tab paths with `\`** → the default path keeps backslashes, `C:\notes\untitled.md`, and isn't normalized to `/` (Task 2 test `default path keeps native separators`).
5. **Typing in the new tab then `Mod-s`** → writes exactly the typed text with LF, because the empty base has no line endings to copy (Task 3 test `first save of a new file writes LF`).

### Task 2: Path helpers

**Files:**
- Modify: `src/tabs/paths.ts`
- Test: `src/tabs/paths.test.ts`

**Interfaces:**
- Produces: `export function withMarkdownExtension(path: string): string` and `export function newFileDefaultPath(activePath: string | null): string`.
  - `withMarkdownExtension`: looks only at the part after the last `/` or `\`. If that name has no `.` at index ≥ 1, it returns `path + ".md"`. Otherwise it returns `path` unchanged. It works on the raw string (no `parse` normalization), so separators survive.
  - `newFileDefaultPath`: with `null` it returns `"untitled.md"`. Otherwise it returns `activePath` up to and including its last `/` or `\`, followed by `"untitled.md"`.

- [ ] **Step 1: Write the failing tests:**

```ts
describe("withMarkdownExtension", () => {
  test("appends .md when the name has no extension", () => {
    expect(withMarkdownExtension("/p/idea")).toBe("/p/idea.md");
    expect(withMarkdownExtension("/p/.notes")).toBe("/p/.notes.md");
    expect(withMarkdownExtension("/p/my.project/idea")).toBe("/p/my.project/idea.md");
    expect(withMarkdownExtension("C:\\my.project\\idea")).toBe("C:\\my.project\\idea.md");
  });
  test("keeps any existing extension", () => {
    for (const p of ["/p/idea.md", "/p/idea.markdown", "/p/idea.txt", "C:\\p\\idea.md"])
```

### Task 3: The `new` command (host, app, keys, empty page)

**Files:**
- Modify: `src/host.ts` (interface + `tauriHost`)
- Modify: `src/test-host.ts` (fake)
- Modify: `src/app.ts` (`COMMANDS`, `keyCommand`, `run`)
- Modify: `src/ui/empty.ts` (copy)
- Test: `src/app.test.ts`

**Interfaces:**
- Consumes: `createFile` from `native.ts` (Task 1), and `withMarkdownExtension` and `newFileDefaultPath` (Task 2).
- Produces:
  - `Host.pickNewFile(defaultPath: string): Promise<string | null>`, documented as "Native save dialog; null when cancelled". `tauriHost` calls `save({ defaultPath, filters: OPEN_FILTERS })` from `@tauri-apps/plugin-dialog`.
  - `Host.createFile(path: string): Promise<boolean>`: true when created, false when it already existed.
  - `FakeHost`: `newPicks: (string | null)[]` (used in order; empty → `null`), `newDefaults: string[]` (each `defaultPath` received), `createErrors = new Map<string, string>()`, and `pickNewError: string | null` (when set, `pickNewFile` throws it). `createFile` pushes `createFile <path>` to `calls`, throws on `createErrors`, returns false if the path is in `files`, and otherwise calls `setFile(path, "")` and returns true.
  - `Command` gains `"new"` (put it first in `COMMANDS`). `keyCommand` maps `Mod-n` (no Shift) → `"new"`.
  - `run("new")`: `pickNewFile(newFileDefaultPath(active?.path ?? null))`. A throw sets status `Could not show the save dialog: <error>`; `null` → return. Otherwise `path = withMarkdownExtension(picked)` and `created = await createFile(path)`. A throw sets status `Could not create <path>: <error>`. Then `await this.openPaths([path])`. If `!created` **and** the path is now open in a tab, set status `<baseName(path)> already exists; opened it.` *after* `openPaths` resolves, because `openNow` clears the status.

```ts
describe("new file", () => {
  test("creates an empty file at the picked path and opens it clean", async () => {
    await app.start();
    host.newPicks = ["/proj/idea.md"];
    await app.run("new");
    expect(host.text("/proj/idea.md")).toBe("");
    expect(activePath()).toBe("/proj/idea.md");
    expect(app.active?.doc.isDirty()).toBe(false);
    expect(ui.statusLine).toBe("");
  });
  test("appends .md when the name has no extension", async () => {
    host.newPicks = ["/proj/idea"];
    await app.run("new");
    expect(activePath()).toBe("/proj/idea.md");
    expect(host.files.has("/proj/idea")).toBe(false);
  });
  test("cancel does nothing", async () => {
    await app.run("new");
    expect(host.calls.some((c) => c.startsWith("createFile"))).toBe(false);
    expect(app.tabs).toHaveLength(0);
  });
  test("dialog starts in the active tab's folder, or with just the name", async () => {
    await app.run("new");
    await app.openPaths(["/docs/a.md"]);
    await app.run("new");
    expect(host.newDefaults).toEqual(["untitled.md", "/docs/untitled.md"]);
  });
  test("existing file opens unchanged", async () => {
    host.newPicks = ["/docs/a.md"];
    await app.run("new");
    expect(host.text("/docs/a.md")).toBe("alpha\n");
    expect(host.writes).toHaveLength(0);
    expect(activePath()).toBe("/docs/a.md");
    expect(ui.statusLine).toBe("a.md already exists; opened it.");
  });
  test("appended name that is already open focuses its tab", async () => {
    await app.openPaths(["/docs/a.md", "/docs/b.md"]);
    host.newPicks = ["/docs/a"];
    await app.run("new");
    expect(paths()).toEqual(["/docs/a.md", "/docs/b.md"]);
    expect(activePath()).toBe("/docs/a.md");
  });
  test("create error shows a status and opens nothing", async () => {
    host.newPicks = ["/ro/x.md"];
    host.createErrors.set("/ro/x.md", "permission denied");
    await app.run("new");
    expect(ui.statusLine).toBe("Could not create /ro/x.md: permission denied");
    expect(app.tabs).toHaveLength(0);
  });
  test("dialog error shows a status", async () => {
    host.pickNewError = "boom";
    await app.run("new");
    expect(ui.statusLine).toBe("Could not show the save dialog: boom");
    expect(host.calls.some((c) => c.startsWith("createFile"))).toBe(false);
  });
  test("first save of a new file writes LF", async () => {
    host.newPicks = ["/proj/idea.md"];
    await app.run("new");
    ui.view.dispatch({ changes: { from: 0, insert: "# Idea\n\nmain point" } });
    await app.run("save");
    expect(host.text("/proj/idea.md")).toBe("# Idea\n\nmain point");
  });
  test("the macOS menu runs it", async () => {
    await app.start();
    host.newPicks = ["/proj/idea.md"];
    host.menu("new");
    await vi.waitFor(() => expect(activePath()).toBe("/proj/idea.md"));
  });
});
```
